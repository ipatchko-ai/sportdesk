# CLAUDE.md — Инструкции для проекта

## О проекте

Полный клон сайта https://dnsjkfn.pythonanywhere.com/ — платформы поиска и бронирования детско-юношеских футбольных турниров, лагерей и кэмпусов.

**Название площадки:** SportDesk  
**Оригинал принадлежит заказчику.** Цель: задеплоить идентичную копию на Vercel + Supabase.

## Команды

### Разработка
```bash
# Установить зависимости
npm install

# Запустить краулинг
npm run crawl

# Запустить dev-сервер (после Фазы 5)
npm run dev
```

### Supabase
```bash
# Применить миграции
supabase db push

# Залить данные
supabase db reset
```

### Vercel
```bash
# Деплой
vercel --prod
```

3. **Без TODO и заглушек**: только рабочий код
4. **Фиксация решений**: все изменения в PROGRESS.md
5. **Тесты перед деплоем**: визуальные + функциональные
