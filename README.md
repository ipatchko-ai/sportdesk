# Football Booking Clone

Полный функциональный и визуальный клон платформы поиска футбольных турниров.

## 🎯 О проекте

Клон сайта https://dnsjkfn.pythonanywhere.com/ — платформы для поиска и бронирования детско-юношеских футбольных турниров, лагерей и кэмпусов в Европе.

**Цель:** Создать идентичную копию на современном стеке (Vercel + Supabase) с полным сохранением функциональности и визуала.

## 🚀 Быстрый старт

```bash
# Клонировать репозиторий
git clone <repo-url>
cd football-booking-clone

# Установить зависимости
npm install

# Установить браузеры Playwright
npx playwright install chromium
```
